# Hao Player 0.2.1

修复高质量播放时临时对象持续积累导致内存膨胀、画面停止的问题，并让增强功能的实际运行状态可见。

## 更新

- 每帧释放 Core ML / Core Image 临时对象，保留显示队列仍在使用的画面。720p 高质量连续播放 10 分钟，稳定期内存为 505–550 MiB；修复前曾达到约 33.7 GiB 并停止更新。
- 区分用户选择与实际生效状态；性能不足提示掉帧并保留所选档位，取消自动降档。处理失败暂停音画，由用户重试或关闭失败功能后继续。
- 增加实际呈现帧率、补帧显示数、阶段耗时与本地诊断导出；支持同帧超分对比和顺序流畅度对比。
- IFRNet-S 使用图像输入输出并保留源分辨率；修正 Anime4K 输出缓冲区所有权和系统快档资源释放。
- 修复只读沙盒书签、暂停后跳转画面刷新、播放终点状态，以及拖放覆盖层影响进度拖动等问题。

## 验证与边界

- 0.2.1（构建号 2）Release 构建成功，59 项自动回归通过，0 失败。
- ZIP 解包后的应用已实际启动，完成 MKV 续播、Anime4K 生效、暂停和退出；“关于”确认版本 0.2.1 (2)。DMG 校验通过，挂载后内容与 ZIP 中的应用逐文件一致。
- 应用和 5 个 FFmpeg 动态库同 Team 签名；沙盒开启，无 Homebrew 运行时依赖。
- **高质量 720p24→48fps 持续目标仍未达标**，部分 1080p 快档组合也未达到持续性能门槛。内存修复不等于所有性能目标通过。
- 高质量与 Anime4K 双开完成一分钟内存复测，不作为十分钟稳定性或实时达标承诺。现有画质样本也不足以支持高质量普遍优于快档。
- 字幕尚未提供。完整数据见 [增强验收报告](../reports/2026-09-09-enhancement.md) 与 [内存修复报告](../reports/2026-09-10-memory.md)。

## 安装包

- `HaoPlayer-0.2.1.dmg`：将 HaoPlayer 拖入“应用程序”。
- `HaoPlayer-0.2.1.zip`：同一份应用。
- 需要 macOS 26+、Apple Silicon。

附件沿用 0.2.0 的 Apple Development 签名，**未公证**，其他 Mac 可能无法直接打开。本机没有 Developer ID Application 证书；本次是 GitHub Release，不是 Mac App Store 上架。

FFmpeg 以 LGPL 2.1 动态链接，许可证和目标码见仓库 `Resources/LICENSES` 与 `Vendor/FFmpeg/dist`。书面提供联系：support@hao.app。
