## 状态与责任

| 事实 | 修复前 | 修复后 |
|---|---|---|
| 文件访问 | 只读文件授权与书签申请不一致 | `FileOpening` 创建只读安全书签；正常沙盒不扩大目录权限 |
| 文件切换 | 先停止旧视频，再尝试新文件；异步完成没有代次校验 | 新文件准备成功才切换；`PlaybackEngine` 在主线程管理切换代次；迟到结果不生效 |
| seek（跳转） | 丢弃早于目标的画面，但保留前面的声音；过度丢弃未来画面 | 音频按采样裁掉目标前的数据；画面等待正确时间；声音和画面都检查跳转代次 |
| 暂停预览 | 暂停后不解码也不绘制 | 解码目标附近一帧并显示，保持暂停 |
| 文件结束 | 仅停止解码，界面仍显示播放中 | 等剩余内容播放结束，进入结束状态；再次播放回到零秒 |
| 方向键 | 依赖视图焦点的局部监听 | 应用菜单命令统一处理左右五秒跳转 |
| 关窗 | 只保存进度 | 播放器窗口关闭前暂停并保存；许可证窗口不触发 |
| 增强效果 | 只有用户选择，没有实际档位反馈 | 保留选择，另显示实际降级状态；处理与重置使用同一把锁 |

文件切换可类比 Vue 的请求序号：只有最新选择对应的请求能更新页面。播放控制状态在主线程修改，后台解码使用锁保护队列与代次，旧声音不能在跳转后再次被排入。

## 删除或替换的旧逻辑

- 删除“比当前时钟超前两秒就丢弃画面”的兜底。旧跳转结果由代次拒绝，合法的未来画面等待显示。
- 删除重复的方向键监听，改用菜单快捷键。
- 删除控制栏重复的悬停回调。
- 删除先停旧视频再打开新文件的路径及其无用方法。
- 播放编排对象移除 `@unchecked Sendable`，明确由 `@MainActor` 管理；后台播放会话保留其受锁保护的跨线程实现。
- 保留增强降级能力，补上用户可见的实际状态，不把开关选中当成效果已生效。
