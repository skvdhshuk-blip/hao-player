# Hao Player 0.2.3

流畅档现在只保留「关 / 快」，隐藏尚未达到持续实时目标的「高质量」入口。

## 更新

- 主界面移除高质量选项，同步更新提示和功能说明。快档继续使用系统补帧；性能不足提示掉帧，处理失败暂停并允许重试或手动关闭。
- 优化内部 IFRNet-S 缓冲区和色彩空间对象复用，避免重复分配；显示队列仍持有的画面不会被覆盖。高质量实现保留用于后续优化，当前没有用户入口。
- 性能详情新增「临时对象释放」「增强与释放合计」，持续验收将释放开销计入完整处理耗时。
- 保留每轮临时对象释放，防止内存持续积累。测量未发现批量释放可以解决高质量卡顿的证据。

## 验证与边界

- 0.2.3（构建号 3）Release 构建通过。自动回归 61 项通过、0 失败；另 1 项需要专用素材的自然视频画质验收未运行，不计为通过。真实 GPU / 模型回归已执行。
- ZIP 解包后的应用完成 FLV 续播、播放、暂停、快档选择和退出检查；界面仅显示「关 / 快」。本次短测没有获得可靠的屏幕呈现统计，不作为实时帧率验收。
- DMG 校验通过，DMG、ZIP 和原打包应用内容逐文件一致；应用及 5 个 FFmpeg 动态库同 Team 签名。
- 沙盒开启，发布包仅包含三项既定沙盒权限，无 get-task-allow，无 Homebrew 运行时依赖。
- 高质量 720p24→48fps 持续目标仍未达标，部分 1080p 快档组合此前也未达到持续门槛。本版不宣称所有增强组合实时达标，详见[性能定位与优化报告](https://github.com/skvdhshuk-blip/hao-player/blob/v0.2.3/docs/reports/2026-09-10-quality-optimization.md)。
- 字幕尚未提供。

## 安装包

- `HaoPlayer-0.2.3.dmg`：将 HaoPlayer 拖入「应用程序」。
- `HaoPlayer-0.2.3.zip`：同一份应用。
- `SHA256SUMS-0.2.3.txt`：安装包校验值。
- 需要 macOS 26+、Apple Silicon。

附件使用 Apple Development 签名，**未公证**，其他 Mac 可能无法直接打开。本机没有 Developer ID Application 证书；本次为 GitHub Release，不是 Mac App Store 上架。

FFmpeg 以 LGPL 2.1 动态链接，许可证和目标码见仓库 `Resources/LICENSES` 与 `Vendor/FFmpeg/dist`。书面提供联系：support@hao.app。
