# App Store Connect 文案（简体中文）

名称：Hao Player

副标题：本地视频，默认 Anime4K

宣传文本：
拖进片子就能播。默认 Anime4K Fast A，可选流畅档。不建库、不上网、不追番。

关键词：
视频,播放器,Anime4K,超分,插帧,本地,mkv,番剧,Apple Silicon

描述：

Hao Player 是给 Mac 用的超轻量本地播放器。一个 App，把文件拖进去就能播。

能播
- mp4 / mov / m4v（系统解码）
- mkv / webm / avi / ts / flv（自建 LGPL FFmpeg + VideoToolbox）

增强
- 默认开启 Anime4K Fast A 超分，可关
- 流畅档：关 / 快（系统补帧）
- 性能不足保留所选档位并提示掉帧；处理失败暂停，由你选择重试或关闭失败功能
- 插帧在源分辨率做完，再进 Anime4K

明确没有
- 没有字幕
- 没有媒体库、网盘、账号
- 没有网络。只读你打开或拖进来的本地文件

系统要求
- macOS 26 或更新
- Apple Silicon

许可证
自身代码 Apache-2.0。FFmpeg 以 LGPL-2.1-or-later 动态链接。Anime4K 与 IFRNet-S 为 MIT。完整文本在应用「许可证」。书面提供（三年）：可联系 support@hao.app 索取该版本的目标文件和链接输入，以便用修改过的 LGPL 库重新链接。
